# Admin UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the admin SPA with a dedicated dark shell, Tailwind v4, and shadcn-vue components per `docs/superpowers/specs/2026-07-20-admin-ui-design.md`, without changing public gallery visuals or APIs.

**Architecture:** Keep public CSS in `src/style.css`. Add Tailwind + shadcn under an admin stylesheet that skips Tailwind Preflight (so the public site is not reset). Nested `/admin` routes render inside `AdminLayout.vue` (sidebar + topbar). Login stays outside the shell but still uses the admin theme via `.admin-root`. Screens swap scoped CSS for shadcn primitives; behavior and `adminApi` calls stay the same.

**Tech Stack:** Vue 3 + TypeScript + Vite + Bun, Tailwind CSS v4 (`@tailwindcss/vite`), shadcn-vue (Reka UI), Inter + Instrument Sans.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-20-admin-ui-design.md` is authoritative
- Admin only — do not restyle public views
- Palette hex values exactly: bg `#0c0c0e`, panel `#16161a`, border `#2a2a30`, fg `#e8e8ea`, muted `#9a9aa3`, accent `#7c9cff`
- Typography: Inter (UI), Instrument Sans (brand wordmark only)
- No API / backend changes
- No Tailwind Preflight on the global document (protect public styles)
- Package manager: **Bun** (`bun add`, `bunx`)
- Existing Vitest specs must pass (update selectors when markup changes)
- Prefer `data-testid` over fragile class selectors in tests

## File map

```
apps/web/
  components.json                          # shadcn-vue config
  src/
    admin.css                              # Tailwind (no preflight) + admin theme tokens
    style.css                              # UNCHANGED public styles
    lib/utils.ts                           # cn() helper
    components/ui/{button,input,...}/      # shadcn primitives
    components/admin/AdminLayout.vue       # sidebar + topbar shell
    components/admin/AdminPageHeader.vue   # optional small helper for titles
    views/admin/*.vue                      # restyled screens (remove scoped CSS)
    App.vue                                # hide public header on /admin*
    router/index.ts                        # nest admin routes under AdminLayout
    main.ts                                # import admin.css
  vite.config.ts                           # @tailwindcss/vite + @ alias
  tsconfig.json / tsconfig.app.json        # @ paths
  index.html                               # Google Fonts link for Inter + Instrument Sans
```
